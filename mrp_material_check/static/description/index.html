MRP Material Check

Before a manufacturing order is produced, check every component against the stock at its source location. A popup lists each shortage — needed, in stock, shortage — and in Block mode only a Manufacturing Manager can continue.

Free | Free · LGPL-3 · Only needs Manufacturing · One setting
😓The Problem
  • ✗ Odoo lets you click Produce All even when components are out of stock, so on-hand quantities can go negative.
  • ✗ Negative stock leads to wrong inventory figures that someone has to correct later.
  • ✗ Operators do not see which component is short or by how much at the moment they produce.
  • ✗ There is no role-based gate: any manufacturing user can mark an order as done with missing components.
🎯The Solution
  • ✓ Check on produce — the module checks every open component move when the order is marked as done.
  • ✓ Clear popup — each short component with Needed, In Stock, Shortage and Unit, highlighted in red.
  • ✓ Two modes — Warn lets anyone continue; Block lets only Manufacturing Managers continue.
  • ✓ One setting — choose the mode in Manufacturing → Configuration → Settings; Warn is the default.

Frequently Asked Questions

When exactly does the check run?
When a manufacturing order is marked as done (the Produce All button). Confirming, starting or checking availability work as in standard Odoo.
Which stock is compared?
For each component line that is not done or cancelled, the quantity to consume is compared with the on-hand quantity at the line's source location, converted to the line's unit.
What's the difference between Warn and Block?
Warn: the popup lists the shortages and anyone can press Continue Anyway. Block: only users with the Manufacturing Manager role can continue; other users can only cancel.
Where do I choose the mode?
Manufacturing → Configuration → Settings → Insufficient Material Behaviour. Warn is the default after install.
What happens when there is enough stock?
Nothing changes: no popup is shown and the order is produced exactly as in standard Odoo.
Does it need Odoo Enterprise?
No. It works on Community and Enterprise and only depends on the standard Manufacturing (mrp) app.
